# AIR SYNTH

AIR SYNTH is a dark, performance-focused iPhone synthesizer prototype.

It includes:

- A generated AIR SYNTH visual style built into the app background
- App icon generated from the same visual direction
- Real-time AVAudioEngine synth sound
- Touch-field pitch and filter control
- Waveform display
- 16-step sequencer
- CoreMIDI note and control-change output

The first build uses the on-screen AIR field for stable input. Camera hand tracking can be added after the synth and MIDI path are proven.
